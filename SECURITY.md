# Security

If you find a secret, a tenant identifier, or personal data in this repository,
including in a recording, please report it privately rather than in a public issue.
Use GitHub's **Report a vulnerability** button on the repository's **Security** tab.

For vulnerabilities in Microsoft Fabric, Fabric Apps, or the Rayfin CLI and SDK
themselves, report to Microsoft through the
[Microsoft Security Response Center](https://msrc.microsoft.com/create-report).
